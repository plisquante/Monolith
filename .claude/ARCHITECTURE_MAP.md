# Architecture map (Rust back end; the Zig back end was removed)
- `monolith/classfile.py bytecode.py world.py program.py` parse, link model, RTA/CHA closed world
- `monolith/rustgen.py` Rust code generator, the only back end; `escape.py` stack escape analysis; `inline.py` inliner; `opclass.py` opcode and intrinsic tables; `vh_modes.py` VarHandle modes; `indy.py` invokedynamic desugar; `proxygen.py` Proxy and MethodHandle stubs; `reflectmeta.py` annotations and generics metadata
- `monolith/patches.py` loads `patches/rust/manifest.json`; `patches/rust/*.rs` hand-written Rust for hot methods
- `monolith/classlib.py` builds the class library (Java overlays compiled with the JDK), content-addressed under the classlib build directory
- `monolith/__main__.py` CLI: `analyze` only; `build` refuses and points to the Rust tools
- `monolith/rt/` Rust runtime: `rt.rs` object and class model; `gc.rs` tracing collector (to be replaced; the rest of the runtime reaches it through `heap.rs`); `heap.rs` heap facade; `natives*.rs` java.lang, reflect, nio, net, sys, jni, rhi natives; `vh.rs` VarHandle; `sync.rs` monitors; `audio*.rs` mixer and device layer; `desk/` windowing; `prof.rs` allocation profiler
- `tools/mcbuild_rust.py` Minecraft pipeline (desktop and `--android`); `build.sh` and `build.bat` wrappers
- `tools/rt_typecheck.py` runtime type-check gate; `rt_deps/` vendored crates and the `check` crate
- `classlib/src/` Java overlays of JDK classes; `runtime/java_nolwjgl/` Java runtime without LWJGL (input to the transpiler)
- `android/touchcore` TouchCore Android launcher. Its native core is Rust (`android/touchcore/native`, `cargo test` 28/28), linked by `tools/build_touchcore_apk.py` with the NDK; the APK builds and its `.so` exports `tc_init`, `tc_tick_frame`, `tc_shutdown`. Not run on a device yet
- `tests/rust/` Rust unit tests; `monolith/stack_tests.py` Rust codegen differential tests against a JDK 25 reference; `tests/run_tests.py` is the differential harness for the Rust back end (`SKIP` lists the programs that need a display, network or JNI library)
- `.claude/hooks/guard.py` PreToolUse guard
