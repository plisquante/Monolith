# Architecture map
- `monolith/classfile.py bytecode.py world.py program.py` parse, link model, RTA/CHA closed world
- `monolith/zigen.py` Zig codegen; `indy.py` invokedynamic desugar; `proxygen.py` Proxy + MethodHandle stubs; `reflectmeta.py` annotations/generics metadata
- `monolith/__main__.py` CLI (transpile in child process, then zig build-exe); classlib builds are per JDK + source hash under `classlib/build/`
- `runtime/rt.zig` object model, GC, threads; `natives.zig` java.lang/reflect/Unsafe; `io.zig` `nio.zig` `nio_ch.zig` files; `jni.zig` JNI bridge; `varhandle.zig`
- `classlib/src/` Java overlays of JDK classes (Class, Thread, MethodHandle(s), Proxy, StackWalker, ...); JavaLangAccess is generated by `tools/gen_jla.py`
- `tools/mcbuild.py` Minecraft pipeline (download JDK/libs/assets, transpile, launchers); `build.sh/bat` wrappers
- `android/touchcore` TouchCore Android launcher (src, jni, res, AndroidManifest); built by `tools/build_touchcore_apk.py`, CI `.github/workflows/build-so.yml`; shipped APK in `releases/`
- `runtime/java_nolwjgl` Java runtime without LWJGL (SDL3/GLES3/OpenAL); `runtime/*_shim.zig` GL/AL shims; `rhi*.zig` render hardware interface (gl, vk)
- `patches/` Zig patches applied to generated output (`manifest.json`); `tests/java` differential test sources; `.claude/hooks/guard.py` PreToolUse guard
